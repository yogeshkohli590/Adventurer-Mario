# Adventurer-Mario
A colorful Mario-style platformer game built with Flutter and Flame. This project includes animated UI, game screens, enemies, levels, coins, power-ups, and a complete APK build workflow for Android deployment. Created as a fun game development project with interactive keyboard/touch controls and a polished home screen experience.
This is a Flutter game project that generates an Android APK and can be run on mobile or emulator. It includes assets, level data, UI screens, and a complete game loop with characters, enemies, coins, and gameplay states.
